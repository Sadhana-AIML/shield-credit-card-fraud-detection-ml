About This Project
🎓

Credit Card Fraud Detection Using ML

A college-level machine learning project that demonstrates how financial institutions detect fraudulent transactions in real time. This system trains classification models on synthetic transaction data and exposes a REST API for live predictions.

Python 3.x Flask scikit-learn NumPy Pandas HTML5/CSS3 Vanilla JS REST API
🌲
Random Forest
An ensemble of 100 decision trees trained using bagging. Best accuracy for imbalanced datasets like fraud detection.
📈
Logistic Regression
A linear model that outputs probabilities using a sigmoid function. Fast, interpretable baseline for binary classification.
🌿
Decision Tree
A rule-based model that splits data based on feature thresholds. Highly interpretable and visual.

📐 Features Used

FeatureDescription
amountTransaction amount in USD
hourHour of the day (0–23)
distanceDistance from cardholder's home (km)
transaction_countNumber of transactions in last 24h

API Endpoints

POST /api/train — Train model
GET /api/metrics — Get metrics
POST /api/predict — Single prediction
POST /api/batch — Batch predictions
